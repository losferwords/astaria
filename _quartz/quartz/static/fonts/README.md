# Local site fonts

Regular/bold Alegreya SC and regular/semibold IBM Plex Mono include their full Latin and Cyrillic coverage. WOFF2 files were converted from the upstream TTF files without subsetting.

Sources (downloaded 2026-10-16):

- <https://github.com/google/fonts/tree/main/ofl/alegreyasc>
- <https://github.com/google/fonts/tree/main/ofl/ibmplexmono>

Both families use the SIL Open Font License; the original license files are included alongside the fonts. The site serves these files locally and needs no Google Fonts request during builds or browsing.
